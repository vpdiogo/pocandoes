# Architecture Decision Records

Record decisions that change project boundaries, dependencies, or operations. Use sequential numbers and one decision per document. Include context, the decision, alternatives, and consequences. When a decision changes, add a superseding ADR and link both records; preserve the history.

Template:

- Title and status (proposed, accepted, or superseded).
- Context and problem.
- Decision and rationale.
- Alternatives considered.
- Consequences and limitations.
