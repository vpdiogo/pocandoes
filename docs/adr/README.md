# Decisões arquiteturais

Registre decisões que alteram limites, dependências ou operação do projeto. Use números sequenciais e uma decisão por documento. Inclua contexto, decisão, alternativas e consequências. Quando uma decisão mudar, acrescente outra ADR que a substitua e ligue os dois registros; preserve o histórico.

Modelo:

- Título e status (proposta, aceita ou substituída).
- Contexto e problema.
- Decisão e justificativa.
- Alternativas consideradas.
- Consequências e limites.
